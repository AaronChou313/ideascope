# 本交付包检查记录

检查日期：2026-09-10。检查对象是计划包中的契约、示例与 HTML 原型，**不是生产科研智能体**。

## 实际完成

`contracts-validation.json`：JSON Schema 自身有效性、合法补丁正例、未知字段/越权操作/无依据 sourced 判断反例、示例跨记录引用与唯一性、TypeScript strict 编译、场景 JSON 可解析性。

`prototype-validation.json`：15 项交互及运行检查；包含节点与证据、演示对话、分支切换/新建、文献筛选、方向保存、设置弹窗、JSON/SVG 导出、首页导航、响应式尺寸、运行错误及外部请求检查。1600×1000 用于主要截图；另检查 1440×900、1280×800、390×844 页面无横向溢出。

截图来自 Chromium 实际渲染。主工作台、首页、设置与窄屏页面经过视觉查看；其他截图供后续人工对照。测试期间没有调用外部模型或文献 API。

## 检查边界

容器浏览器的策略阻止了 file:// 导航，因此测试通过 Playwright set_content 装入自包含 HTML；没有在该环境直接验证双击文件打开。原型没有外部脚本/样式依赖，适合作为本地浏览器样式参考。

没有测试生产 React 工程、图补丁 reducer、IndexedDB 迁移、多标签页写锁、真实 Provider/CORS、实际付费成本、完整可访问性审计或 GitHub Pages 发布。它们仍属于路线中的待开发/待验收事项。原型交互通过不代表这些能力完成。

`MANIFEST.json` 提供包内文件的 SHA-256 与字节数（不含它自身），用于校验交付内容；ZIP 已做内部完整性检查。
