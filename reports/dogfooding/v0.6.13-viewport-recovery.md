# v0.6.13 Research Map viewport recovery

日期：2026-09-11

## 复现链路与根因记录

1. 检查 `ResearchMap` 后确认 `onMoveEnd` 未区分用户平移与程序化 `fitView` / `setCenter`。
2. viewport 保存会克隆整个 Workspace；原 layout effect 依赖 `branch.graph.nodes`、`branch.graph.edges` 与 `branch.view` 对象，因此纯视口变化也会再次触发布局和程序化移动。
3. 原回调可在 positions 尚未完成布局时写入空 Map，且持久化入口没有过滤非有限 viewport / position。
4. 一旦瞬态 viewport 被保存，重新进入会话仍可能恢复到全图之外。

## 修复后的保护

- Graph layout 只响应 Branch ID / Graph revision，单纯 viewport 更新不重跑。
- 程序化移动不通过用户 `onMoveEnd` 回写。
- viewport 必须为有限数值且 zoom 位于 0.28～1.7。
- 空 positions 不覆盖已持久化节点位置。
- 恢复时检测“没有任何节点与画布相交”，自动 fit view。
- 工具栏提供“找回地图”，一次恢复全部节点并持久化新 viewport。
