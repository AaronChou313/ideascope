## 记录边界

- 使用浏览器中已由用户配置的 DeepSeek Provider；不读取、不复制、不记录 API Key。
- 只记录产品可观察行为、聚合数量、必要错误摘要和修复结论。
- 不保存 Authorization header、完整请求、完整模型原始响应或用户密钥。
- 公开 Literature Source 的实时返回会变化；数量仅代表当次运行。

- 计划场景：首次探索、节点上下文继续、全局追问、方向转移、刷新恢复、来源限流降级

## 运行记录

### 0. 前置检查

- 结果：已有真实探索会话可恢复；当前会话显示 9 个节点、28 条 Evidence。
- 图结构：1 个 Root，节点包含多层 primary hierarchy，并存在 cross relation。
- 上下文：Composer 显示明确节点上下文，普通选中与研究上下文在界面上可区分。

### 1. 首次探索第一次尝试

- 输入：四足机器人足端传感器对定位导航的作用。
- 进度到达“正在制定检索策略”，随后严格 Intent Plan Schema 拒绝 Provider JSON。
- 用户可见结果：“模型输出格式不符合研究结构契约；现有研究数据未被覆盖。”
- 数据安全：0 节点、0 Evidence；输入仍保留，可以重试。
- 根因：检索计划中的可选 Session Profile Patch 与核心检索计划共用一个严格 Schema；DeepSeek 对可选 patch 的字段变体使整个有效计划失败。
- 修复：增加有界 `normalizeIntentPlanOutput()`；标题和查询仍按严格预算收敛，无效可选 Profile enrichment 降级为空 patch，不阻塞搜索。

### 2. 首次探索第二次尝试

- Intent Plan 修复有效：成功生成 4 组英文查询并进入 Literature Search。
- 第 1 轮取得 8 条候选资料；Crossref、Semantic Scholar、arXiv 在当前浏览器环境报告 `source_unavailable`，OpenAlex 资料保留并继续综合。
- DeepSeek Synthesis 返回后再次被严格 Graph Synthesis Schema 拒绝。
- 根因：Provider 返回的研究内容具备核心字段，但包含常见枚举别名/额外解释字段；直接 strict parse 使整轮失败。
- 修复：增加有界 `normalizeSynthesisOutput()`。只接受规定字段类型和预算，映射有限的 kind/relation 别名，丢弃未知 cross link，再进入原有严格 Schema 和 Graph Tree/Patch 校验；不会绕过 Evidence、parent、cycle 或引用完整性约束。

### 3. 首次探索成功复测

- 查询：4 组。
- 参与路由的来源：4 个。
- 候选资料：8 条。
- 最终 Evidence：8 条。
- Graph：13 节点，其中 1 Root、4 条主要路线、8 个二级节点。
- 有来源判断：12 条。
- 会话标题自动生成：“四足机器人足端感知与导航”。
- 可展开进度实际显示理解、计划、检索轮次、候选数量、来源降级、综合和地图更新。

### 4. 基于节点继续

- 仅点击“足端本体感知与状态估计融合”时只打开节点详情；点击“基于此节点继续探索”后 Composer 才出现 context chip。
- 问题：足端接触约束如何进入 EKF/因子图，以及接触状态和滑移鲁棒处理。
- 结果：Graph 由 13 增至 18 节点，Evidence 由 8 增至 15；新增 5 个节点挂在所选路线局部，包括不变 EKF、接触因子、接触判断、滑移鲁棒处理和延迟重评估。
- 旧节点保留。
- 发现问题：普通局部追问会重写既有 Root 标题。
- 修复：既有 Branch 的 Root 默认不可被后续轮次改名；只有新方向 Branch 可以设置自己的 Root。

### 5. 方向转移

- 输入：停止研究定位，转向足端感知在复杂地形理解和可通行性判断中的作用。
- 结果：创建新 Branch；Graph 增至 22 节点、Evidence 增至 23。
- 新 Branch Root：“足端感知与复杂地形通行性”。旧定位/状态估计内容仍在继承图中。
- 新增路线：足端力觉地形分类、主动探测、触觉局部几何、地形属性到落足/导航决策。
- 发现问题：方向转移完成后 UI 暂时清除了旧 context，但刷新会从 Branch.focusNodeId 恢复旧节点上下文。
- 修复：创建新 Branch 时不再把旧 context 注入 Agent，并将新 Branch focus 清空。

### 6. 无节点上下文的全局追问

- 清除 context 后输入：“整体来看，当前足端感知用于复杂地形理解的最大研究难点是什么？”
- 结果：节点仍为 22（复用并更新已有节点，没有盲目增长），Evidence 增至 27。
- Root 保持“足端感知与复杂地形通行性”，验证后续全局追问不再改写 Root。

### 7. 刷新恢复

- 浏览器刷新后恢复 22 节点、23 Evidence 的方向转移快照；随后全局追问完成为 22 节点、27 Evidence。
- Session Sidebar 异步恢复全部会话。
- Graph、Evidence、Branch、会话标题和对话均可恢复。
- 手动清除旧测试 context 后再次刷新，context chip 不再出现。

## 结论

- DeepSeek Chat Completions 的真实 Initial → Search → Evidence → Synthesis → Graph 闭环通过。
- 节点局部继续、Branch 方向转移、全局追问和刷新恢复通过。
- 本轮真实流程共暴露并修复：可选 Profile Patch 阻塞计划、Synthesis 常见 JSON 变体阻塞、后续轮次改写 Root、方向转移恢复旧 context（后两项同属上下文/Root 不变量修复）。
- 当前浏览器中 OpenAlex 可用；Crossref、Semantic Scholar、arXiv 本轮均降级为 `source_unavailable`。多来源错误没有终止研究，但这些浏览器端失败仍需后续分别诊断 CORS/服务状态。
