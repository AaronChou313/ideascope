# 视觉与交互原型

双击 `index.html`，可离线打开。首屏是工作台；点左上角品牌或“所有探索”进入首页。无 CDN、无远程字体、无模型/API 请求；只有用户主动打开论文来源链接才会访问外站。

已做的演示交互：地图/列表切换、节点详情、来源详情、示例对话、分支切换、新分支复制、文献搜索、方向暂存、设置分类、能力检查项展示、JSON/SVG 导出、缩放/适应与窄屏视图。

未做：真实 Provider/文献调用、真实自动布局、真实 IndexedDB、生产级导入/迁移、PNG/Markdown 导出。请不要输入真实 API Key（原型输入已禁用）。

`tokens.css` 是生产实现可参照的视觉变量；HTML 单文件只作为视觉基线，生产工程按文档组件化实现。

当前视觉基线已从早期雾绿方案调整为“黑 / 白 / 中性灰 + 蓝色焦点”。以 `index.html` 和 `tokens.css` 为唯一视觉依据。旧版预览图已从交付包移除，避免本地智能体误参考旧配色。
