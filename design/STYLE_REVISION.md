# IdeaScope 视觉修订 · Monochrome Blue

## 本次调整

早期原型的雾白 / 墨青 / 淡绿色方案已废弃。当前唯一视觉基线为：**黑、白、中性灰为主体，蓝色仅用于交互焦点和关键操作。**

主要变化：

- 页面、侧栏、工具栏、普通卡片与研究节点取消淡绿色背景，默认使用白色或极浅中性灰。
- 主文本切换为近黑色，次级信息使用中性灰，不再使用带绿色偏色的灰。
- 主按钮、当前焦点、节点选中边框、活跃关系线使用蓝色。
- 研究节点不再根据语义类型整块着色；通过标签、图标、边框与结构区分。
- hover 使用灰色，selected 才使用蓝色，避免页面默认状态“到处泛蓝”。
- 保留小面积警告 / 错误语义色，但不得扩展成大块彩色组件。
- 去除旧版预览 PNG，避免实现智能体继续参考已废弃的绿色视觉。

## 视觉目标

整体更接近成熟的代码编辑器、研究工具与专业知识工作台，而不是常见 AI SaaS 营销页面。强调内容、结构和工作状态本身，不通过渐变、彩色卡片、柔和有色大背景或“AI 发光效果”营造科技感。

## 实现优先级

1. 先保证全局黑白灰层级与信息密度正确。
2. 再用蓝色建立主操作和当前焦点。
3. 最后处理小面积 warning / danger 等语义状态。
4. 后续深色模式沿用同一逻辑，不做蓝黑渐变或霓虹效果。
