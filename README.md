# IdeaScope · 项目开发计划与设计交付包

**从一个模糊想法，走向有依据的研究方向。**

文档基线：2026-09-10 · 计划修订：1.0 · 产品暂定名：IdeaScope · 建议仓库名：`idea-scope`

这是开发规格、接口草案和可交互视觉原型，不是已经完成的科研智能体产品。命名尚未核查商标与仓库可用性。本文中的版本均是计划版本，不表示已发布；原型中的对话与图结构均是演示。

## 从这里开始

- **完整阅读**：`PROJECT_PLAN_FULL.md`，合并了所有专题文档，便于一次交给本地智能体。
- **先看效果**：打开 `design/index.html`。单文件、无需安装、不调用模型、不发送请求。含研究工作台、新建探索、文献库、方向卡片、模型设置与导出弹窗。
- **启动开发**：把整个目录放进本地项目，读取 `AGENTS.md`，向本地智能体粘贴 `prompts/START_LOCAL_AGENT.md`。
- **持续迭代**：逐阶段维护 `docs/PROGRESS.md`；不要要求智能体一次性完成所有版本。

## 四项不可妥协的约束

1. 运行时为纯前端；GitHub Pages 仅托管静态资源。用户自选模型服务，不内置开发者共享密钥。
2. 只做领域探索、证据整理、辅助思考和方向收敛；不扩展实验、代码训练或论文写作功能。
3. 图展示问题、方法路线、局限与候选方向；论文是证据，不默认成为画布节点。
4. 所有事实性研究判断可追溯；推测必须标为推测。没有检索结果时，不能伪装成完成了调研。

> 依赖版本、在线接口和浏览器兼容性由 v0.1.0 实测并锁定。本包不声称已验证任何真实用户密钥或生产 Pages 域名。
