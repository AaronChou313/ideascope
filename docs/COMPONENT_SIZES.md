# v0.2 组件与布局尺寸基准

本表冻结 v0.2.0-C 的生产实现基准。`design/index.html` 与 `docs/05_DESIGN_SYSTEM.md` 仍是视觉规范来源；这里记录可回归检查的尺寸，不将演示原型作为运行时代码。

| 区域 / 组件 | 桌面基准 | 折叠 / 窄屏规则 |
|---|---:|---|
| 应用顶栏 | 60px 高 | 保持 60px，不随工作区滚动 |
| 左侧研究导航 | 216px 宽 | 1200px 以下折叠为 56px 图标轨道；900px 以下隐藏 |
| 右侧节点详情 | 380px 宽 | 1200px 以下 340px；900px 以下通过“详情”视图单独显示 |
| 中央标题工具栏 | 76px 高 | 小于 900px 时左右内边距为 14px |
| 移动端视图栏 | 不显示 | 小于 900px 时底部 52px，提供地图 / 资料 / 详情切换 |
| 语义节点 | 220px 宽，最小高 132px | 摘要决定实际高度；内部留白 14–16px |
| 常规按钮 / 页签 | 36–40px 高 | 键盘 focus ring 始终可见 |
| 弹窗 | 最大宽度按内容组件约束 | 10px 圆角；初始焦点、Tab 环绕、Esc 关闭并恢复触发点 |
| 内容区卡片 | 14px 圆角 | 700px 以下双列信息降为单列 |

验收视口为 1600×1000、1440×900、1280×800 与 390×844。前三档保持三栏比例且无主页面横向溢出；移动档使用单主视图切换，不同时挤压地图与详情。颜色、字号、间距和语义状态继续由 CSS tokens 与设计系统约束。
